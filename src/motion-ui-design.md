## Software
Software for producing UI animations, grouped by technology and output format (video, prototype, code, etc.) - with links to tutorials and plugins.
### Video, gif, presentation
* [Adobe After Effects](https://www.adobe.com/products/aftereffects.htm) - Industry-standard animation and creative compositing app for motion graphics, visual effects, video and web.
* [Using After Effects for UI Animation Prototypes](https://www.youtube.com/watch?v=w67z1YhPFKM&feature=youtu.be) - Video.
* [UI Animation tutorials](https://uxinmotion.net/).
* [How to Use After Effects for Web Animation Prototypes](http://webdesign.tutsplus.com/tutorials/how-to-use-after-effects-for-web-animation-prototypes--cms-21451) - Video.
* [MtMograph summits](http://mtmograph.com/summits/) - Video.
* [After Effects CC Essential Training on Lynda](http://www.lynda.com/After-Effects-tutorials/After-Effects-CC-Essential-Training/122431-2.html) - Video.
* [BodyMovin](https://github.com/bodymovin/bodymovin) - Converter from AE to SVG/canvas.
* [Squall](http://www.marcuseckert.com/squall/) - Converter from AE to iOS.
* [Apple Motion](https://www.apple.com/sg/final-cut-pro/motion/) - MacOS app for motion graphics, titling, and 2D/3D compositing.
* [Adobe Photoshop](http://www.adobe.com/sea/products/photoshop.html) - Raster graphics editor that can also produce GIF UI animations.
* [Adobe Flash](http://www.adobe.com/products/flash.html) - Software for vector graphics, animations, and games.
* [Apple Keynote](https://www.apple.com/ru/mac/keynote/) - MacOS presentation app suitable for high-fidelity animation and prototypes.
* [How To Prototype UI Animations In Keynote](http://www.smashingmagazine.com/2015/08/animating-in-keynote/).

* [Principle For Mac](http://principleformac.com/) - MacOS tool for animated, interactive interfaces.

### JavaScript
* [GreenSock](http://greensock.com/) - High-performance animation for the modern web.
* [Velocity.js](http://velocityjs.org/) - Accelerated JavaScript animation.
* [Impulse](http://impulse.luster.io/) - High-performance interactions for mobile web.
* [AniJS](http://anijs.github.io/) - Animations through data attributes.
* [Snabbt.js](http://daniel-lundin.github.io/snabbt.js/) - Minimal JavaScript animation library.
* [Processing.js](http://processingjs.org/) - JavaScript library for Processing visual programming.
* [Dynamics.js](http://dynamicsjs.com/) - Physics-based animations for JavaScript.
* [Mo.js](https://github.com/mojs/mojs) - Motion graphics toolbelt for the web.
* [AnimateTransition](http://rapid-application-development-js.github.io/AnimateTransition/) - Transitions for blocks and popups.
* [Animate Plus](https://github.com/bendc/animateplus) - CSS and SVG animation library for modern browsers.
* [Gravitas.js](https://github.com/iamralpht/gravitas.js) - Physics simulations for JavaScript.
* [Popmotion](https://popmotion.io/) - JavaScript motion engine for interactions.
* [anime.js](http://animejs.com/) - Lightweight JavaScript animation library.
* [useAnimations](https://useanimations.com/) - Micro-animation icon library.
### SVG
* [SnapSVG](http://snapsvg.io/) - JavaScript library for working with SVG assets.

* [BonsaiJS](https://bonsaijs.org/) - Lightweight graphics library with SVG renderer.
* [Vivus.js](http://maxwellito.github.io/vivus/) - Animate SVGs with a drawn effect.
* [Walkway.js](http://connoratherton.com/walkway) - Animate SVG line, path, and polyline elements.
* [Transformicons](http://www.transformicons.com/) - Animated icons, symbols, and buttons using SVG and CSS.
